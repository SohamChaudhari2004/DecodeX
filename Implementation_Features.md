# Mobility Logic System Features & Analytics

This document outlines the core technical features and analytical statistics implemented in the Mobility Logic application, designed for your final documentation submission.

## 🗺️ Interactive Map Features
*Each feature corresponds to a core capability built into the MapLibre GL visualization engine.*

* **Interactive 2D / 3D Isometric View**: Seamlessly toggles the camera between a flat 2D overhead perspective and a 60-degree angled 3D isometric projection without reloading the application.
* **Node Intelligence HUD**: Clicking any transit stop opens a Heads-Up Display revealing localized data including total boardings, alightings, specific CAGR growth, and a list of intersecting routes.
* **Congestion Heatmap Overlay**: Visualizes traffic density across the network using colour-coded route segments (red/orange/yellow) to immediately highlight severe chokepoints and structural bottlenecks.
* **System Route Visualization**: Toggles global visibility for all operating routes across the city, providing a macro-level understanding of the entire transit network's span.
* **Predictive ML Forecast Overlay**: Projects 7-day future passenger demand using a trained Random Forest model, featuring an interactive timeline slider to visualize daily allocation shifts.
* **Optimal Path Engine (Dijkstra's Algorithm)**: Calculates the absolute fastest multi-route journey between any two selected stops, factoring in specific route-type speeds (Express, Feeder, etc.), geodesic distances, and transfer points.
* **Animated Route Tracking**: Features dynamic webGL animations including a drawing effect and a glowing tracker pulse that continuously rides the computed optimal path from origin to destination.

## 📊 Analytical Dashboard Statistics
*These statistics represent the data insights generated by the backend Python ML pipeline and visualized in the React dashboards.*

* **Executive KPI Summary**: Top-level system metrics including total network passenger volume, peak load values, system-wide CAGR, and critical bottleneck severity indices.
* **Annual Growth & Congestion Elasticity**: A dual-axis analysis comparing Year-over-Year passenger expansion against congestion severity, demonstrating how traffic delays correlate with ridership elasticity.
* **Zonal Heatmaps & Intelligence**: A spatial matrix displaying the density of boardings versus alightings across the 7 major operational zones, identifying primary commercial and residential hubs.
* **Structural Imbalance & Load Profiles**: Highlights the specific disconnect between localized feeder networks and primary trunk routes, pinpointing over-serviced vs. under-serviced corridors.
* **Seasonality & Event Volatility**: Analyzes weekend divergence patterns and major event-driven passenger surges to quantify demand volatility outside of standard commuter hours.
* **H2 2025 AI Traffic Forecast**: Machine Learning predictions projecting passenger volume trends for the upcoming 6 months, complete with high/low confidence intervals.
* **ML Pipeline Output & Validity**: Exposes the underlying Machine Learning mechanics, including evaluation metrics (R², MAE) and feature importance analysis, proving the mathematical validity of the forecasts.
